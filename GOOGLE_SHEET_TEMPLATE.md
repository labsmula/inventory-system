---

## 🚀 Cara Menggunakan Template

### **Step 1: Buka Template**
1. Klik link di atas
2. Template akan terbuka di Google Sheets

### **Step 2: Make a Copy (Buat Salinan)**
1. Klik **File > Make a copy**
2. Masukkan nama baru (contoh: "Inventory System - Warung Kopi")
3. Klik **OK**
4. Copy template akan tersimpan di Google Drive Anda

### **Step 3: Rename (Opsional)**
1. Klik judul sheet di pojok kiri atas
2. Rename sesuai nama UMKM (contoh: "Inventory System - Warung Kopi")

### **Step 4: Selesai!**
Google Sheet template sudah siap digunakan.

---

## 📋 Struktur Sheet

Template ini berisi **4 sheets**:

1. **Master Produk** — Database produk dengan margin
2. **Stok Current** — Tracking stok real-time
3. **Transaksi Masuk** — Log restock
4. **Transaksi Keluar** — Log penjualan

---

## ✨ Fitur Template

- ✅ **Formulas** otomatis (margin %, stok akhir, status)
- ✅ **Conditional Formatting** (warna kuning/merah jika low stock)
- ✅ **Sample Data** (5 produk contoh)
- ✅ **Headers** sudah diatur dengan benar

## 🔗 Langkah Berikutnya

Setelah copy template, lanjut ke:
1. **Setup Google Apps Script** (Lihat file `scripts/Code.gs`)
2. **Deploy sebagai Web App** (Lihat file `WEB_APP_URL.md`)
3. **Akses Web App** dan mulai gunakan!
