# v1.2.0 Planning - Modern Dashboard

**Mula Inventory System**
**Version:** 1.2.0 (Planning Phase)
**Date:** 2026-04-06
**Status:** Planning

---

## 🎯 Overview

Refactor UI menjadi **modern dashboard** dengan perspektif **Growth Analyst** (data-driven, actionable insights) dan **Creative Director** (minimalist, modern, trustworthy).

---

## 📊 Design Principles

### Dari **Growth Analyst**:
1. **Trend over Snapshot** — Tampilkan trends (grafik), bukan hanya angka tunggal
2. **Actionability over Complexity** — Fokus metrics yang bisa di-action
3. **Story over Raw Numbers** — Explain apa arti data (insights, recommendations)
4. **Relevance over Completeness** — Track penting saja, jangan overwhelming

### Dari **Creative Director**:
1. **Minimalist & Clean** — White space, card-based design, subtle shadows
2. **Trustworthy** — Consistent colors, clear hierarchy, professional
3. **Brand Consistency** — Mula Labs green (#4CAF50) + accent colors
4. **Modern Touches** — Rounded corners, smooth transitions, micro-interactions

---

## 🎨 UI Layout

### Sidebar Navigation (Left)
- **Navigation Links:**
  - Dashboard
  - Products
  - Transactions
  - Reports
  - Settings
- **Quick Actions:**
  - + Add Product
  - + Stock In
  - + Stock Out
  - 📷 Scan Barcode
- **Profile:**
  - User avatar
  - Name
  - Logout

### Main Content Area

#### **1. KPI Cards (Top Row)**
4 cards dengan metrics + trend indicator:
- **Total Products** (📦) → +5 this week ↑
- **Low Stock Items** (⚠️) → -3 items ↓
- **Out of Stock** (🔴) → 0 items ✓
- **Inventory Value** (💰) → IDR 1.5M +12% ↑

#### **2. Charts Section**
- **Stock Trend Chart** (Line chart) → Stok harian (7/30 hari)
- **Category Distribution** (Pie chart) → Produk per kategori (F&B, Retail, Jasa)
- **Top Selling Products** (Bar chart) → Produk terjual terbanyak

#### **3. Alerts & Insights Section**
**High Priority Alerts:**
- ⚠️ "3 produk low stock (stok < 5)"
- 🔴 "Warung Kopi belum update stok 3 hari"

**Actionable Insights:**
- 💡 "Restock Tepung Terigu sebelum habis (stok sisa 2kg)"
- 📈 "Kopi Arabica meningkat 20% minggu ini"

#### **4. Recent Activity Feed**
Timeline aktivitas terakhir:
- 10:05 AM → Stock In: Kopi Arabica (5kg)
- 09:30 AM → Stock Out: Tepung Terigu (2kg)
- Yesterday → Product Added: Susu UHT

#### **5. Quick Actions (Floating/Fixed)**
- **+ Add Product** → Modal form
- **+ Stock In** → Quick restock
- **+ Stock Out** → Quick sale
- **📷 Scan Barcode** → Camera scanner

---

## 🚀 Interactive Features

### 1. Real-Time Data Updates
- Auto-refresh data setiap 30 detik
- Live counter untuk stok changes
- Notification badge untuk new alerts

### 2. Interactive Charts
- Hover effects → Show detail data per titik
- Click chart → Drill-down ke detail produk
- Time range selector (7 hari, 30 hari, 90 hari)

### 3. Quick Actions
- Keyboard shortcuts:
  - `Ctrl + N` → Add Product
  - `Ctrl + I` → Stock In
  - `Ctrl + O` → Stock Out
  - `Ctrl + B` → Scan Barcode
- Modal pop-ups untuk fast input

### 4. Smart Search
- Global search bar di top:
  - Cari produk berdasarkan SKU/nama/kategori
  - Cari transaksi berdasarkan tanggal/produk
  - Filter by status (low stock, out of stock)

### 5. Dashboard Personalization
- Drag-and-drop widgets untuk custom layout
- Show/hide widgets based on preference
- Set default dashboard view per user

## 📱 Modern Design Elements

### Color Palette
- **Primary:** Mula Labs Green (#4CAF50)
- **Secondary:** Ocean Blue (#2196F3)
- **Accent:** Warning Orange (#FF9800), Danger Red (#F44336)
- **Background:** Light Gray (#F5F5F5)
- **Card White:** #FFFFFF with subtle shadow

### Typography
- **Headings:** Montserrat or Poppins (bold)
- **Body:** Open Sans or Roboto (regular)
- **Numbers:** Lato or Roboto Mono (for metrics)

### Components
- **Cards:** White background, rounded corners (8px), subtle shadow (0 2px 8px rgba(0,0,0,0.1))
- **Buttons:** Gradient backgrounds, hover effects, ripple animation
- **Charts:** Soft colors, grid lines, smooth curves
- **Tables:** Zebra striping, hover effects, sort arrows

### Animations
- **Page Transitions:** Smooth fade-in (300ms)
- **Hover Effects:** Scale up (1.05x), shadow increase
- **Loading:** Spinner or skeleton screens
- **Notifications:** Slide-in from top-right

## 🔧 Technical Implementation

### Frontend Technologies
- **Chart Library:** Chart.js or ApexCharts (lightweight, responsive)
- **Icon Library:** Font Awesome or Material Icons
- **Framework:** Vanilla JS (keep it simple) or Vue.js (if needed)

### Backend Updates (New Functions)
- `getDashboardTrends(days)` — Stock trend data
- `getCategoryDistribution()` — Category breakdown
- `getTopSellers(limit)` — Best selling products
- `getRecentActivity(limit)` — Activity feed

### Performance Optimizations
- Lazy load charts
- Debounce search input
- Cache dashboard data (5-minute cache)
- Optimize API calls
